# DeathPlateau Engine

TypeScript game server (a fork of LostCityRS Engine-TS). Game content lives in the
sibling repo DeathPlateau-Content; bugs and decisions live on DeathPlateau-Bugs.

## Working rules (all DeathPlateau repos)

- Write a short plain-language TLDR for the owner at the top of every PR and report.
- Game behaviour follows 2006 RuneScape where it is documented; otherwise follow Old School.
  Say which source you used in the PR.
- Merge order across repos: Content, then Engine, then Client.
- Merge a PR only when every check is green. Never skip, disable or loosen a check to get green.
- Post owner decisions on the tracker issue, first line bold and verbatim:
  `**Decision from the owner, 24 Nov 2026: "<owner's words>"**`
- Claim a tracker issue with the `claude-working` label before working it; remove it when you stop.
- Use subagents for read-heavy sweeps.

## Branches

- `377-wip` is the integration branch. Branch from it, PR into it.
- `dev-logging` is what the live server runs. It only takes `--no-ff` merges from `377-wip`.
  Never commit to it directly.
- Content must be on the matching branch (`377-wip`).

## Setup and checks

Content is read from `../content` (set `BUILD_SRC_DIR` to change it). Node 24.

```bash
npm ci
npm run lint
npx tsc --noEmit
npx tsx tools/envcheck.ts
npx tsx tools/tradingpostcheck.ts
npx tsx tools/quest/WordingCheck.ts
npx tsx tools/pack/StaleCheck.ts
```

Sims (`tools/sim/`, see its README). Always rebuild the pack first; the exit code is the verdict:

```bash
BUILD_VERIFY=false BUILD_SRC_DIR=../content npx tsx tools/pack/Build.ts
npm run rsa && npm run sqlite:migrate
npx tsx tools/sim/<name>.ts
```

- Keep `tools/sim/known-failing.txt` empty. Ratchet baselines (`tools/sim/*-baseline.txt`) only move in the good direction.
- `data/quests.json` is generated by `tools/quest/ExportHelper.ts`. Regenerate it; never hand-edit it.
- Pre-commit runs prettier and eslint through lint-staged.

## Conventions

- PR titles are Conventional Commits (CI enforces it): `fix(scope): plain-English outcome`.
- Cite tracker issues as `DeathPlateau-Bugs#N` and cross-repo halves as `DeathPlateau-Content#N`.

## Security

- Never commit `.env`, `*.pem`, `*.sqlite`, player or runtime data under `data/`, or `public/`. Leave `.gitignore` entries in place.
- Never regenerate, replace or overwrite the login RSA key.
- Keep the placeholder token in `package.json` (`tickets:check`) a placeholder.
- Read secrets only from environment variables or GitHub secrets. Never write a secret value into code, workflows, PRs, issues or logs.
- Do not add hostnames, IP addresses, server paths or secret names to commits, PR text or issues.
